## 5. Migration command

There is no migrate subcommand and no SQL file under `scripts/`. `cmd/wheretoken-hosted/main.go` calls `store.Migrate` after `hosted.Open` and before listen, with a 30 second timeout. `Migrate` is `internal/hosted/migrate.go` (`CREATE TABLE IF NOT EXISTS`, then `ensureColumns`, then `backfillVerifiedIdentity`).

The command that runs it is starting the new binary under the documented PM2 name, after step 4 and after step 6 has produced the binary:

```bash
pm2 restart wheretoken-hosted
```

That `pm2` line is the operator command for the documented process name. The repo has no ecosystem file, so the on-disk script PM2 is already running was not seen. If the process is not loaded yet, the ADR's deploy sequence says `nginx -t`, reload, then PM2 start of `wheretoken-hosted` bound to `127.0.0.1:3400` with the env file. Do not bind `0.0.0.0:3400`.

If `Migrate` fails, the process exits before listen and the old process must still be the one PM2 will roll back to. Watch the PM2 log. Do not treat a failed start as a finished migration.

## 6. Build the hosted binary and SPA

Off the server (the ADR says the host has no Go toolchain). From a checkout of the merge commit that was tagged `v0.7.7`:

```bash
git checkout v0.7.7
scripts/build-hosted.sh
```

`scripts/build-hosted.sh` writes `dist/hosted/` unless you pass another directory. It runs:

```bash
GOOS=linux GOARCH=amd64 CGO_ENABLED=0 go build -trimpath -ldflags "-s -w" -o "$out/wheretoken-hosted" ./cmd/wheretoken-hosted
( cd web && VITE_HOSTED=1 VITE_DEMO= npm run build )
```

`VITE_DEMO` is empty. The script exits if `dist/hosted/web` contains `sample/`, `演示数据`, or a `sample/` fetch in `web/assets`. Do not build with `VITE_DEMO=1`. That flag is the GitHub Pages demo in `docs/deployment.md`, not this host.

The script does not pass `-X main.version`. `resolveVersion` in `cmd/wheretoken-hosted/main.go` returns the link-time value when it is not `dev`, otherwise `debug.ReadBuildInfo` main version, otherwise `dev`. A local `go build` therefore leaves health able to report `dev`. Goreleaser's `-X main.version={{.Version}}` applies to `./cmd/wheretoken` only. Record:

```bash
go version -m dist/hosted/wheretoken-hosted
```

`vcs.revision` must be the merge commit tagged `v0.7.7`. A health body of `dev`, or the old pseudo-version, is not a stamped `v0.7.7` string. Do not mark READY on either.

Copy `dist/hosted/wheretoken-hosted` into the path PM2 executes, and copy `dist/hosted/web` to a new directory under the documented SPA root `/www/wwwroot/wheretoken-releases/<merge-commit-sha>/`. Point the nginx `root` at that new directory. Keep the previous directory for rollback. The live nginx file was not observed; `nginx -t` is the ADR's check:


