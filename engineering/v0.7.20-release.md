## Hosted

The public host was not upgraded. This Mac cannot open SSH or HTTPS to the public A record: both fail in the local network stack before authentication or TLS (`Can't assign requested address`, connect failure in 0 ms). The repository has no Hosted deploy workflow. `.github/workflows/hosted-readonly-check.yml` only GETs `/api/health` and the public profile. DNS, Clash, Keychain, nginx, PM2, and MySQL were not changed. No backup was taken on the server because the host was not reached, and no rollback was required because the running process was not replaced.

The last health body observed from this Mac, on an earlier intermittent read, was `v0.7.11+profilefix.4ade1aa`. An independent GitHub runner check is recorded at https://github.com/rainhuang0220/whereToken/actions/runs/44360408018. That run is a read, not a deploy.

To finish the Hosted upgrade later, an operator with an existing login on that VPS follows `engineering/v0.7.7_operator_runbook.md`: copy the current binary, env file, nginx root, and a MySQL dump, record their SHA-256, build with `sh scripts/build-hosted.sh` from the `v0.7.20` tag, then replace the process with the previous copies kept for rollback. Do not delete ledger or projection rows.
