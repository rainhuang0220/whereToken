    About this data

    This page is live in the browser. The usage numbers are a locally generated public snapshot, not a live cloud sync. No prompts, paths, or transcripts are published.

    • Tokens tracked are the ledger values this snapshot can actually measure. Coverage windows can differ by source.
    • Total = miss + cache read + cache create + output. Reasoning is not added twice.
    • Missing usage is shown as unavailable (—), never $0.
    • Cost, if present, is an API list-price equivalent, not a subscription bill.
